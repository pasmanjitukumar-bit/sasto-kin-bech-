# SastoKinBech hosting capability check

The application stack has not yet been selected. The existing screenshot shows
cPanel and active SSL, but runtime and database capabilities remain unverified.

Please provide the hosting provider and plan, plus these capabilities from cPanel:

- PHP versions and extensions: PDO MySQL, fileinfo, GD or Imagick, mbstring, OpenSSL.
- MySQL or MariaDB availability and version.
- Whether Node.js applications are supported; available version if supported.
- SSH or Terminal, Composer, and cron availability.
- Document root for sastokinbech.com and whether a private directory outside it is available.
- Upload/storage limits and whether outbound HTTPS requests and email delivery are allowed.

Do not send passwords, database credentials, API keys, or hosting session links.

If PHP is available, temporarily upload `hosting-check.php` through File Manager,
visit that file on your domain, copy the JSON report, and delete the check file.
It reads capability information only and does not connect to a database.
